# VPN сайт

Простой сайт для личного кабинета VPN с возможностью привязки Telegram.

## Установка

1. Установите Node.js 18+.
2. Откройте папку `vpn сайт`.
3. Выполните:
   ```bash
   npm install
   ```
4. Скопируйте `.env.example` в `.env` и заполните значения:
   - `SESSION_SECRET` — любая секретная строка.
   - `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота.
   - `TELEGRAM_BOT_NAME` — имя вашего бота без `@`, например `MyVpnBot`.
   - `XUI_API_URL` — URL вашего 3X-UI API.
   - `XUI_API_KEY` — ключ доступа к API 3X-UI.
   - `XUI_API_USER_PATH` — путь API для получения данных пользователя (можно оставить `/api/v1/get-user`).
5. Запустите сервер:
   ```bash
   npm start
   ```

## Использование

- Откройте `http://localhost:3000`
- Зарегистрируйтесь или войдите в личный кабинет.
- После регистрации вам будет выдан VPN ключ.
- На странице кабинета отображается ключ и адрес сервера.
- Перейдите в раздел "Telegram" для синхронизации аккаунта.

## Технические настройки

- VPN сервис называется `Djoker: Shadow Net`
- Адрес сервера по умолчанию: `213.165.38.205:2053`
- Протокол по умолчанию: `wireguard`

## Готовый сайт

- Статический фронтенд уже собран и находится в `public/index.html` с ассетами в `public/assets`.
- Запуск: `npm start` и откройте `http://localhost:3000`.

## Примечания

- В текущей версии используется простая база SQLite.
- Для продакшена замените `express-session` на надежное хранилище и настройте HTTPS.
